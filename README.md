# Chakran Infra — Static Website Template

This package is a self-contained responsive HTML/CSS/JS recreation inspired by the public Chakran Infra website.

## Files
- `index.html` — complete page
- `style.css` — responsive styling
- `script.js` — mobile navigation and form interaction

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Notes
The design uses CSS-generated visual placeholders rather than copying third-party image assets. Replace the project/portfolio backgrounds with your licensed project photos in `style.css` if desired.
